# Hydrippo

A no-ads water tracker from SideQuest Studio. Slide the water line on your own bottle to log a drink; Drip the hippo soaks deeper as you go. Your day ends while you sleep, not at midnight.

- **Try it on your phone:** install the latest test build from
  https://github.com/bnoel19902/Hydrippo/releases/download/test-latest/hydrippo-test.apk
  (a new one is built automatically on every push to `main`).
- **Try it in a browser:** open `www/index.html` in Chrome (use the device toolbar for phone size).
- **Tests:** `npm test` (logic) and `python3 tests/sim/simulate.py` (usage simulator).
- **How it's built:** `docs/PRODUCT_NOTES.md`. Rules for working on the code: `CLAUDE.md`.
- **Store listing, privacy policy, Play Console answers, graphics:** `store-listing/`.
- **Scripts:** `tools/` (privacy page, single-file test build, widget art, store graphics).

Fonts: Sniglet and Atkinson Hyperlegible Next, both SIL Open Font License (see `www/fonts/`).
